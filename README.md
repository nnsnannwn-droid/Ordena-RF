# Мир орденов

Многостраничный сайт-каталог орденов Российской империи, СССР и России.

## Страницы
- `index.html` — главная
- `catalog.html` — каталог и поиск
- `history.html` — хронология
- `order.html?id=an` — подробная страница выбранного ордена
- `files.html` — материалы и экспорт документов
- `assistant.html` — помощник
- `account.html` и `profile.html` — вход и личный кабинет

Все страницы используют общие `assets/styles.css` и `assets/app.js`. Проект не требует сборки: достаточно открыть `index.html` или включить GitHub Pages для ветки `main`, папка `/ (root)`.
